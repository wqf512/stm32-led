## 实验信息
- 提交Git编号：248b723
- 芯片：STM32F103C8T6
- 软件：STM32CubeIDE

## 实验功能
使用**HSI内部高速时钟**，实现LED每500ms闪烁一次。系统时钟参数：
- HCLK：64MHz
- PCLK1：32MHz
- PCLK2：64MHz

## 工程搭建步骤
1. 打开STM32CubeIDE，新建工程，选择芯片STM32F103C8T6。
2. 选择LED对应的引脚，设置为输出。
3. 时钟配置：启用HSI内部时钟，将HCLK设置64MHz，保存并自动生成工程代码。
4. 在main.c里面添加代码，控制LED亮灭。
5. 代码写完，编译工程。

## 源代码运行方法
1. 用STM32CubeIDE打开工程文件夹。
2. ST-Link把开发板连电脑，开发板上电。
3. 编译代码，确认没有报错。
4. 点击下载，程序烧录到单片机。
5. 下载完成，开发板自动运行，LED每隔500ms闪烁。
